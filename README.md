# NODO — ecommerce

Plantilla de e-commerce moderna en React + Vite + TypeScript, con Supabase (auth, catálogo, pedidos, storage e imágenes).

## Arranque local

1. Copiá `.env.example` a `.env` y completá:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
2. `npm install`
3. `npm run dev`

## Stack

- React + Vite
- Supabase (Postgres, Auth, Storage)
- Panel admin: productos, categorías y envíos
